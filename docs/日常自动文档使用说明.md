# Vimoose 0.10.0 日常使用

直接启动控制即可，不需要选择模式、老师或目标文档，也不需要课堂校准。摄像头主要拍手；不用让双肩、手肘入镜。

## 指向和点击

食指指向移动光标；先对准目标，再把拇指和食指捏合、松开完成左击。与中指捏合是右击，食指捏合保持约2秒进入拖拽。捏合接触时光标保留在已瞄准位置，不跟随弯曲后的指尖跳动。

新出现的手需要连续稳定约150毫秒。完整手丢失或安全过滤拒绝结果时立即取消动作；恢复后需重新张开，再点击。默认关闭单点续跟踪，避免鼻部、背景继承手指身份。

## 自动适配文档

| 前台窗口 | 张掌动作 | 保留操作 |
|---|---|---|
| Microsoft PPT 全屏放映／演讲者视图 | 向自己左侧摆动下一步，右侧上一步；包含动画步进 | 指向、捏合 |
| Microsoft PPT 普通浏览／幻灯片浏览 | 左右摆动切换幻灯片 | 指向、捏合；文字编辑时暂停翻页 |
| Microsoft Word 文档 | 向下移动翻下一屏，向上翻上一屏；左右动作也可前后翻屏 | 指向、捏合 |
| 其他窗口 | 日常鼠标滚轮 | 不自动发送文档翻页键 |

张掌先稳定约0.3秒，再侧向摆动或轻微摆动配合翻腕；完成后回正约0.3秒。一直停在偏转姿势不会连续翻页。单次动作需在约1秒内完成；模糊、出框、丢手和切换窗口会取消当前动作。

不向后台文档发指令，不主动抢焦点。切换文档后需重新张掌准备；旧动作不会转发到新文档。PPT 文本选择、特殊编辑视图、菜单、对话框、保护视图或按住修饰键时不翻页。Word 中允许阅读时已有插入光标，但翻屏不会输入或修改正文。

设置中可关闭“自动适配前台 PowerPoint／Word”，恢复通用鼠标手势；可单独关闭张掌翻页。暂停／恢复是 Ctrl+Alt+G，紧急停止是 Ctrl+Alt+Esc，退出是 Ctrl+Alt+Q。

## 范围和限制

本版验证的是 Windows 桌面版 Microsoft Office，不把 WPS、PDF 阅读器、网页版算作已支持。面部检测仅用于排除可疑小骨架，不识别用户身份。手贴住脸且完全遮挡时可能宁可暂停；建议手稍微离开脸侧。

便携使用可解压后启动 Vimoose.exe；正常升级可运行安装器，先退出旧版避免两个程序同时控制。旧0.9.0发布文件和本轮修改前源码备份均保留。

接口依据：[PowerPoint View](https://learn.microsoft.com/en-us/office/vba/api/powerpoint.view)、[Word LargeScroll](https://learn.microsoft.com/en-us/office/vba/api/word.window.largescroll)。
