## 已完成的真实 Office 用例

- PPT 第一页动画：PageDown 后页码仍为 1，动画点击索引由 0 到 1；PageUp 后回到 0。
- PPT 普通幻灯片：第二页下一步进入第三页；安全模式不推进真实演示；退出放映后不再识别为操作目标。
- Word 下翻一屏时滚动比例由 0 到 4，上翻可返回；70%、100%、150% 缩放均验证向下滚动。
- 两个 Word 文档同时打开：绑定第一个时，第二个处于前台不获得控制；关闭第一个后绑定解除。

脚本只关闭自己创建的内容。为了测试，脚本可激活自建测试窗口；产品的 Office 适配器不调用这些激活逻辑。

尚未完成 PPT 所有首尾页设置、复杂多步动画、真实扩展屏／演讲者视图、Office 原生菜单／模态对话框完整矩阵及 Word 文档尾部测试。单元测试不能代替这些实机项。

## 原视频口径与缺口

文件 `video_20260904_104119.mp4` 长约 22.047 秒；顺序解码全部 663 帧，以 15 Hz 取 331 帧进行模型推理，覆盖整个时间段，不是只看截图。初标文件为 `tests/fixtures/classroom_video_labels.json`，包含准备、动作、保持、回位及预摆区间，动作方向和细分边界仍需老师确认。

原片为近距离手势示范，肩部部分不在画面内。完整链路按双肩可见和身份连续性要求拒绝授权，未检出可用控制手。隔离回放得到 319 帧手部特征，4 个初标动作各触发一次，另外 3 个动作漏检；部分侧掌帧手部尺度不足、短暂无结果／多候选会取消当前动作。不能将“没有误触”表述为“全部动作通过”。

隔离诊断模板按正掌和方向示范设定，不是完整六次校准，也不属于独立留出测试集。需要补拍完整上半身和控制手、左右各三次校准、动作间明确回正的片段，继续修复漏检，并保留现有安全拒绝规则。

完整流水线离线处理 331 个采样帧耗时约 34.17 秒（约 9.7 个采样帧／秒），包含解码和 Python 编排；不是实时摄像头稳态 FPS，也不是最终课堂硬件基准。当前不能宣称达到 15 FPS 或提交延迟 P95 ≤ 200 毫秒。200 毫秒事件丢弃边界有自动测试，不等于性能验收通过。

目录包安全模式另运行 4 秒：无手部检出的摄像头画面下，采集／识别约 21.7 / 22.0 FPS，帧到结果延迟 P95 约 47 毫秒，正常退出且无模型错误。此处没有执行有效教师动作，不能替代多人课堂 FPS 或动作指令提交延迟。独立测试配置从版本 9 迁移到 10，原 `pinch_engage=0.51` 保留，日常配置未用于此验收。

## 必须完成的现场项

1. 1、2、3 米分别至少 100 次有效动作，成功率 ≥ 95%，重复／反向事件为零。
2. 至少 200 次学生举手、学生手更高／更近、两手同时出现和交叉换位，无错误翻页；45 分钟正常讲课无非预期翻页。
3. 双屏演讲者视图、前后台与对话框切换、文档首尾和关闭重开不串控。
4. 在目标电脑测量稳态识别 FPS、动作判定至提交的 P95；分别记录模型时间、排队时间和 Office 调用时间。
5. 实际安装后离线模型加载、旧配置迁移、全局快捷键、异常释放与退出卸载。

旧发布包不覆盖；本次开始前的源码快照为 `artifacts/pre-classroom-20260904-source-tree.zip`。恢复时应逐项比对，不自动覆盖用户现有修改。

## 打包依赖排错

首次目录包启动失败，错误为 QtCore 的 DLL 导入缺少过程。符号核查确认：构建器从桌面 PDF 工具链的 PATH 中误收集 ICU 78，导出 `ucnv_open_78`，而 Qt 需要 `ucnv_open`。已将构建进程的 PATH 限定为 Python 与 Windows 系统目录，并加入真实目录包符号回归测试；不修改用户系统 PATH 或删除工具链文件。最终二进制模型自检证据为 `packaged-model-check.json`。
