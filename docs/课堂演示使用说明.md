# Vimoose 0.9.0 课堂演示使用说明

本版是课堂功能的待验收构建。独立课堂模式已经接入，但原视频完整回放尚未通过，不是正式课堂验收完成版。具体结果见《课堂演示验收记录》。

## 适用范围

- Windows 10/11 x64、桌面版 Microsoft PowerPoint 和 Word；不含 WPS 和网页版。
- 摄像头在讲台附近，老师双肩、控制侧手肘和整只手必须入镜。1～3 米是验收目标，不是本版已经验证的距离。
- 模型随程序打包，运行时离线，默认不录像、不保存师生图像，不做人脸识别。
- 普通鼠标模式保留；课堂模式不发送光标移动、点击、拖拽或普通滚轮指令。

## 首次使用

1. 打开右侧“课堂演示”标签，启用课堂模式，点击顶部“启动控制”。
2. 选择老师自己的左手或右手，在预览中拖动框选讲台有效区。“全画面”可重置。设置变化会撤销旧课堂会话，需要重新选人。
3. 点击预览中老师的胸肩区域。浅色框表示候选，绿色框表示已锁定。多人框重叠时，请先调整站位。
4. 点击校准按钮。正对镜头张掌静止一秒，然后按提示向自己的左侧摆动并翻腕、回正三次，再向右三次。校准期间不会控制 Office。
5. 用键盘或鼠标进入 PPT 全屏放映；或者在课堂面板绑定 Word 文档，再手动切回该文档。
6. 正掌稳定后显示“可翻页”：向左为下一步，向右为上一步，每次动作最多一次，回正不触发。

正掌稳定要求 300 毫秒；动作完成窗口为 150～1000 毫秒；触发后冷却 600 毫秒且须回正。动作间请保持短暂停顿，不要连续快速摆手。

如果在暂停状态下开始校准，校准完成后仍然暂停；请主动恢复，再正掌准备。

## PPT 与 Word

- PPT 使用 PageDown / PageUp 成对按下、释放，保留翻页笔的动画推进语义；不强制跳到下一张。
- Word 对绑定窗口调用 LargeScroll，每次上下翻一屏，屏内内容随缩放、视图和窗口大小变化，不等于固定一张纸。不修改正文或强制切换视图。
- 程序不启动放映、不抢焦点、不向后台广播。切到其他窗口、菜单、对话框或按住修饰键时禁止输出。
- 扩展屏及演讲者视图已有识别路径，但仍待真实双屏验收。某些 Office 的 HWND 是受限成员：此时仅允许唯一 PowerPoint 进程、唯一全屏放映的原生窗口关联；多个实例或放映时可能暂停，不猜测。
- Word 必须主动绑定；切换文档不会转移控制权，关闭目标后需重新绑定。Office 接口失败则暂停，不退化为向任意窗口发按键。

## 暂停、恢复和换人

- `Ctrl+Alt+G`：暂停／恢复。恢复不能绕过教师锁定和正掌准备。
- `Ctrl+Alt+Esc`：紧急停止输出并释放按键；`Ctrl+Alt+Q`：安全退出。
- 仅控制手短暂丢失：取消动作，同一只手恢复稳定至少 500 毫秒，再正掌准备。
- 人体丢失、双肩出画、多人重叠或身份不明确：锁定失效，必须重新点选老师，不能自动接管别人。
- 退出 PPT 后保持课堂待命。要恢复普通鼠标，请主动关闭课堂模式。
- 浮层不获取焦点。安全模式中的“提交次数”是模拟提交，不代表 Office 内容实际变化。

## 配置和隐私

配置升级到版本 10，保留旧鼠标参数。保存摄像头、区域、控制侧和校准；不保存跨启动的教师身份或窗口句柄。每次启动都要重新点选老师。摄像头、分辨率、镜像或控制侧变化后校准失效。

常规诊断日志不含图像。开发者显式运行回放脚本时，会在指定输出路径保存数值关键点和状态。分享这些诊断文件前仍应自行检查。

## 安全试用与开发验证

```powershell
.venv\Scripts\python.exe -m gesture_mouse --safe-mode --config artifacts\classroom-test-config.json
.venv\Scripts\python.exe -m pytest
.venv\Scripts\python.exe -m gesture_mouse --verify-classroom-models artifacts\model-check.json
```

`--safe-mode` 同时禁用鼠标、键盘和 Office 真实操作。`--config` 隔离验收配置，不改日常配置；目录包也支持这些参数。

```powershell
.venv\Scripts\python.exe -m scripts.replay_gesture_video --classroom E:\zhuomian\video_20260904_104119.mp4 --output artifacts\classroom-0.9.0\video-full.json --calibration tests\fixtures\classroom_video_diagnostic_calibration.json --labels tests\fixtures\classroom_video_labels.json
```

仓库视频校准文件仅是诊断模板，不满足左右各三次生产校准流程，不要复制到日常配置。`--gesture-only` 绕过教师跟踪，仅定位手势漏检，不能证明防学生干扰；产品界面没有此选项。人工初标的动作方向和时间边界还需要老师确认。

`scripts/verify_office_classroom.py` 会创建临时未保存演示、文档，并在测试期间激活这些窗口，结束时仅关闭自建内容；运行前请完成当前输入。产品的 Office 适配器不包含激活窗口逻辑。

## 已知限制和正式验收

原视频近距离拍摄、肩部部分出画。完整链路无法维持可靠教师锁定；隔离手势回放也存在漏检。需补充肩肘腕完整入镜、正反方向校准和动作间正掌停顿的片段。不能通过关闭身份失效、丢手取消或回正保护来“提高通过率”。

几何关联不是身份认证，不能保证所有换位、遮挡和光照下永不误认。正式使用前应完成 1、2、3 米各 100 次有效动作、200 次学生干扰、45 分钟正常讲课，以及双屏、文档首尾、缩放、菜单和对话框测试；目标设备至少 15 FPS，动作判定至指令提交的 P95 不超过 200 毫秒。
